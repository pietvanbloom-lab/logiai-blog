# LogiAI Blog

Repository für [logiai.blog](https://logiai.blog) — Blog über KI in der Logistik.

## Scope
- Technische & SEO-Optimierung von logiai.blog
- Recherche & Publikation neuer Inhalte
- Versionierung von Design, Templates und Scripts

## Dateien
- `DESIGN.md` — Design-System (Apple-inspired), generiert via `npx getdesign@latest add apple`. Referenz für alle UI/UX-Entscheidungen.
- `index.html` — Preview-Mockup der Startseite im Apple-Stil (single-file, kein Build-Step). Lokal öffnen oder über GitHub Pages hosten.

## Preview lokal öffnen
```bash
open index.html
```

## Stack (geplant)
