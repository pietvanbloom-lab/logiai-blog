LogiAI.blog is a WordPress blog (using Yoast SEO, behind Cloudflare) focused on AI and automation in logistics/supply chain. Content is in English. Active strategy: [[logiai-strategy-2026-06]].

**Why:** Markus is building this as a thought leadership platform for AI in logistics.

**How to apply:** The site IS indexed by Google (confirmed 2026-05-30 audit, `logiai-indexing-audit-2026-05-30.md` in Logistics LAB). `site:logiai.blog` returns homepage + posts; robots.txt allows Googlebot; sitemaps declared. The real gate is RANKING/AUTHORITY: young low-authority domain that does not yet rank for competitive head terms. Target low-competition long-tail EU keywords, build topical clusters with internal links, earn backlinks. Do NOT target head terms (owned by EU Commission, IAPP, big vendors). Open items only Markus can do: pull Search Console Coverage report, confirm sitemap submission, decide AI-crawler policy (robots.txt currently blocks GPTBot/ClaudeBot/Google-Extended, which also blocks AI answer-engine citations). Note: Cloudflare blocks scripted fetches (not Googlebot); use User-Agent curl/8.4.0. GitHub repo: pietvanbloom-lab/logiai-blog. Workspace folder "Logistics LAB" holds strategy docs, audits, skill bundles.
