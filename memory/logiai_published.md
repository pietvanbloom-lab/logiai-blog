**Known issue (Yoast meta via REST):** Yoast meta fields (`_yoast_wpseo_focuskw`, `_yoast_wpseo_title`, `_yoast_wpseo_metadesc`) are NOT writable via REST `meta` field on logiai.blog. Sending them in POST/PATCH /posts returns 201/200 but the values do not persist (confirmed on posts 484 and 486). However, `yoast_head_json` is computed and returned by the public REST endpoint once meta is set, so verification works post-hoc. **Workaround (proven 2026-05-21):** Set Yoast SEO via WP Admin UI through Claude in Chrome: navigate to `/wp-admin/post.php?post=ID&action=edit`, click Yoast SEO sidebar toggle, fill Focus keyphrase, expand Search appearance modal, fill SEO title + Meta description, click Return to your post, click Save. Permanent fix would be a `register_post_meta` mu-plugin entry. **Faster workaround (proven 2026-06-01, most reliable):** drive the block editor's Yoast store from the JS console instead of pixel-clicking the modal: `wp.data.dispatch('yoast-seo/editor').updateData({title:'... %%sep%% %%sitename%%', description:'...'})` then `.setFocusKeyword('kw')`, then `wp.data.dispatch('core/editor').savePost()`. Persists on this site even though direct REST `meta._yoast_wpseo_*` does not. Verify with `yoast_head_json`. Title field accepts `%%sep%%` + `%%sitename%%` replacement vars.

## Duplicate-Check Algorithm

Before passing any story candidate to Phase 3 (Drafting), the skill runs:

1. **Exact title match** against published list. If hit, STOP, escalate to operator.
2. **Pillar + Tag overlap.** If candidate's pillar matches a published article AND >= 3 of its tags overlap with a published article's tags, raise WARNUNG. Operator decides.
3. **Semantic similarity** (only for High-priority candidates in P3, P4, P6 to avoid wasting tokens). Use Haiku 4.5 to compare candidate title plus excerpt against the last 60 days of published titles+excerpts. Threshold 0.7 cosine similarity flags as risk.
4. **Pillar saturation guard.** If proposed pillar already represents >40% of last 30 days output, surface as WARNUNG with current pillar distribution. Currently P5 Agentic AI is in this state.
